## 二、仓库简介

本仓库是本人本学期课程学习的**个人作品集主仓库**，用于集中存放全学期 **16 周**的实验代码、实验报告、运行结果与学习笔记。

- **目的**：完整记录每周学习与动手实践过程，形成可追溯的成长轨迹；
- **原则**：每次实验独立成目录，代码与说明文档放在一起，便于复盘与展示；
- **范围**：覆盖环境搭建、基础语法、数据结构、算法实践、综合项目等阶段性内容。

## 四、目录结构

```text
.
├── .gitignore          # Git 忽略规则：哪些文件不纳入版本管理
├── README.md           # 本文件：仓库总说明书
├── week01/             # 第 01 周实验
│   └── .gitkeep        # 占位文件（让 Git 能跟踪空目录）
├── week02/
├── ...
└── week16/             # 第 16 周实验
```

**每周目录建议这样存放：**

```text
week01/
├── README.md      # 本周实验目的、步骤、结论
├── src/           # 源代码
└── output/        # 运行结果截图或输出文件
```

## 五、快速开始

```bash
# 1. 克隆仓库到本地
git clone <本仓库的 HTTPS 地址>

# 2. 进入仓库目录
cd <仓库名>

# 3. 完成某周实验后，提交并推送
git add .
git commit -m "feat(week01): 完成第 1 周实验"
git push
```

## 六、Commit 提交规范（建议）

统一使用 `<类型>(周次): <描述>` 的格式，方便日后回溯：

| 类型 | 含义 | 示例 |
| :--- | :--- | :--- |
| `feat` | 新增功能/实验成果 | `feat(week03): 完成循环结构练习` |
| `fix` | 修复错误 | `fix(week05): 修正函数返回值错误` |
| `docs` | 只改文档 | `docs: 更新 README 实验目录` |
| `refactor` | 重构代码 | `refactor(week09): 简化文件读写逻辑` |
| `chore` | 杂项/配置 | `chore: 补充 .gitignore 规则` |
